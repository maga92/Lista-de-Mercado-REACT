# Lista de Mercado

Aplicação de lista de mercado desenvolvida para praticar **JavaScript, React e Tailwind CSS**.

O projeto permite adicionar e organizar itens de uma lista de compras, utilizando conceitos de componentes, estados e interação com o usuário.

## Tecnologias

- JavaScript
- React
- Tailwind CSS
- Vite

## Objetivo

Projeto desenvolvido como parte dos meus estudos em desenvolvimento web, com foco em aprender e praticar React na construção de uma aplicação simples e funcional.
